# 띵커벨 이미지 다운로더

띵커벨 엑셀 파일에서 이미지 URL을 추출하여 폴더별로 정리된 ZIP 파일로 다운로드하는 Streamlit 앱입니다.

## ⚠️ 중요 공지

**띵커벨은 해외 IP를 차단합니다!**

- ❌ Streamlit Cloud에서는 작동하지 **않습니다**
- ✅ **반드시 로컬 컴퓨터(한국 내)에서 실행**하세요

## 설치 방법

1. Python 3.7 이상이 설치되어 있어야 합니다.

2. 터미널을 열고 프로젝트 폴더로 이동합니다:
```bash
cd /Users/powerwarez/Desktop/tinkerboard_downloader
```

3. 필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

## 실행 방법

터미널에서 다음 명령어를 실행합니다:

```bash
streamlit run tinkerboard_downloader.py
```

브라우저가 자동으로 열리며 앱이 실행됩니다.

## 사용 방법

1. **엑셀 파일 업로드**: 띵커벨에서 다운로드한 `.xls` 파일을 업로드합니다
   - 파일에는 "보드_page_1" 시트가 있어야 합니다
   - F열(6번째 열)에 이미지 URL이 있어야 합니다
   - A열에 폴더 구분용 텍스트가 있어야 합니다

2. **자동 다운로드**: 앱이 자동으로 이미지를 다운로드하고 ZIP 파일로 만듭니다

3. **ZIP 다운로드**: "띵커벨 이미지 다운로드" 버튼을 클릭하여 ZIP 파일을 저장합니다

## 기능

- ✅ 엑셀 파일(.xls)에서 이미지 URL 자동 추출
- ✅ 폴더별로 구분하여 이미지 정리
- ✅ 진행 상황 실시간 표시
- ✅ 띵커벨 서버 보호 우회 (한국 IP 한정)
- ✅ 자동 재시도 및 에러 처리

## 문제 해결

### 403 에러가 계속 발생하는 경우

1. **해외에서 접속하고 있지 않은지 확인** (VPN 사용 중인지 확인)
2. 한국 내 인터넷 연결 사용
3. 로컬 컴퓨터에서 실행 중인지 확인 (Streamlit Cloud ❌)

### 다른 에러가 발생하는 경우

- 엑셀 파일 형식이 올바른지 확인
- 인터넷 연결 상태 확인
- Python 및 패키지 버전 확인
